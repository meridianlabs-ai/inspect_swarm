Changelog

0.3.0 (2026-10-30)

⚠ BREAKING CHANGES

  • the swarm’s result record moves from the sample store to the transcript (#135)

Features

  • direct messages between members, the messages channel (#130) (fb7e2b1)
  • members that choose their own names (#113) (a2270b0)
  • the dependency-linked critical path, critical_steps_to_answer (#127) (33bf17b)
  • the swarm’s result record moves from the sample store to the transcript (#135) (807e0cd)

Bug Fixes

  • keep board-file links on waits that also reach messages (#137) (3d979b4)

0.2.1 (2026-10-28)

Features

  • raise shared_memory’s default size limits (#110) (114cf7a)
  • the changes command names every changed file (#109) (f84ee01)
  • the shared memory preamble puts tool names, paths and ids in markdown backticks (#99) (ab8bd2c)

0.2.0 (2026-10-27)

⚠ BREAKING CHANGES

  • remove swarm notices; members learn of shared memory changes from tools (#106)

Features

  • new changes command in shared_memory reports changed files without listing the board (#96) (f56b83e)
  • remove swarm notices; members learn of shared memory changes from tools (#106) (aa9ec88)
  • shared memory accepts text that looks like a fence, and the docs say peer text has no protection (#105) (b5ae470)
  • shared memory drops the repeated not-instructions headers (#83) (ce481c6)
  • shared memory fences drop the record and line-range attributes (#86) (2d341af)
  • shared memory fences name the last writer as last_writer (#89) (2b8c740)
  • shared memory has no upper bounds, and Inspect truncates its tools’ results (#93) (4f0657c)
  • shared memory views and waits take a file id as file_id (#90) (d9092e5)
  • swarm notices put tool calls in markdown backticks (#94) (0701835)
  • swarm notices start with [Automatic swarm notice] (#98) (cbe8b26)

Bug Fixes

  • shared memory listings line up their columns when file ids, versions or writers differ in length (#97) (6345c82)
  • validate member limit dicts (#88) (fff3c7e)
